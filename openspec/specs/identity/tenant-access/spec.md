# Tenant Access Specification

## Purpose

定义租户、成员、角色权限与调用凭据的边界，使每个请求在进入任何业务逻辑之前都获得可信的租户与身份上下文，并保证跨租户数据不可达。

## Requirements

### Requirement: 租户生命周期管理

平台管理员 SHALL 能够创建与停用租户。租户编码在平台内全局唯一。被停用的租户，其全部业务请求必须被拒绝。

#### Scenario: 创建租户

- **WHEN** 平台管理员提交唯一的租户编码与名称
- **THEN** 系统创建租户并返回租户标识与状态 `ACTIVE`

#### Scenario: 重复编码被拒绝

- **WHEN** 平台管理员提交已存在的租户编码
- **THEN** 系统拒绝创建并返回可定位到该字段的冲突错误

#### Scenario: 停用后请求被拒绝

- **WHEN** 已停用租户的调用方发起任意业务请求
- **THEN** 系统返回拒绝结果，且不执行任何 Agent 逻辑

### Requirement: 成员归属与角色

用户 SHALL 能够加入一个或多个租户并持有租户内角色。非租户成员不得读取或修改该租户的任一业务资源。

#### Scenario: 添加成员并授予角色

- **WHEN** 租户管理员将某用户加入本租户并授予角色
- **THEN** 该用户后续请求的权限集合包含该角色的权限点

#### Scenario: 非成员访问被拒绝

- **WHEN** 不属于某租户的用户请求该租户的 Agent 列表
- **THEN** 系统返回无权限结果，且响应中不包含该租户任何资源信息

### Requirement: 可信身份与租户上下文

每次请求的租户与用户身份 SHALL 仅从认证凭据解析得到。请求体、查询参数或自定义请求头中携带的租户标识不得参与授权判定。

#### Scenario: 请求体伪造租户标识

- **WHEN** 某租户的调用方在请求体中传入另一租户的标识
- **THEN** 系统仍按凭据解析出的租户执行，且不返回另一租户的任何数据

#### Scenario: 缺少凭据

- **WHEN** 请求未携带有效凭据
- **THEN** 系统返回未认证结果，且不建立租户上下文

### Requirement: API Key 凭据

系统 SHALL 允许为租户创建 API Key 用于业务系统调用。明文 Key 仅在创建响应中返回一次；Key 必须支持过期时间、作用域限制、禁用与轮换。

#### Scenario: 创建 API Key

- **WHEN** 租户管理员创建 API Key 并指定作用域
- **THEN** 系统返回一次明文 Key 与掩码标识，后续任何查询只返回掩码

#### Scenario: 禁用后立即失效

- **WHEN** 管理员禁用某 API Key 后该 Key 再次发起请求
- **THEN** 系统返回未认证结果

#### Scenario: 作用域外调用被拒绝

- **WHEN** 仅被授予读取作用域的 API Key 调用 Agent 执行接口
- **THEN** 系统返回无权限结果且不创建任何执行记录

### Requirement: 操作权限与资源授权联合判定

系统 SHALL 同时判定"主体能否执行某类操作"与"主体能否访问某个具体资源"，二者任一不满足即拒绝。

#### Scenario: 有操作权限但无资源授权

- **WHEN** 用户具备 Agent 编辑权限，但目标 Agent 所属资源未授权给该用户
- **THEN** 系统拒绝该编辑请求

#### Scenario: 授权撤销后新请求被阻断

- **WHEN** 某资源的授权被撤销
- **THEN** 在明确的缓存失效上限内，后续针对该资源的请求被拒绝

### Requirement: 租户数据隔离

所有业务数据 SHALL 归属唯一租户，租户过滤在服务端强制执行。数据库行级安全策略作为纵深防御存在，但不得作为唯一防线。

#### Scenario: 跨租户直接读取

- **WHEN** 某租户用户使用另一租户的资源标识请求详情
- **THEN** 系统返回未找到或无权限结果，且不泄露该资源是否存在

#### Scenario: 绕过应用层查询

- **WHEN** 存在未携带租户上下文的数据库查询路径
- **THEN** 该查询返回空集而非全量数据
