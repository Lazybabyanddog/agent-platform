# Tool Registry Specification

## Purpose

把 Agent 可调用的内部 API 与业务服务注册为带契约、带版本、带风险等级的受管工具，使工具调用在参数、权限与超时上可被服务端强制约束。

## Requirements

### Requirement: 工具注册

系统 SHALL 支持注册 `HTTP` 与 `MCP` 两类接入类型的工具。`HTTP` 工具的配置项包含名称、面向模型的用途描述、请求方法、URL 模板、认证凭据引用与状态；`MCP` 工具的配置项包含名称、面向模型的用途描述、传输方式、服务端地址、远端工具名、认证凭据引用与状态。未显式声明接入类型时按 `HTTP` 处理，以保证既有注册行为不变。

#### Scenario: 注册 HTTP 工具

- **WHEN** 开发者提交工具名称、用途描述、方法与 URL 模板
- **THEN** 系统创建 `HTTP` 工具并返回其标识与首个版本

#### Scenario: 注册 MCP 工具

- **WHEN** 开发者提交工具名称、用途描述、传输方式、服务端地址与远端工具名
- **THEN** 系统创建 `MCP` 工具并返回其标识与首个版本

#### Scenario: 缺少用途描述被拒绝

- **WHEN** 提交的工具未提供描述
- **THEN** 系统拒绝保存，因为缺少描述会导致模型无法正确选择工具

#### Scenario: 接入类型不可识别被拒绝

- **WHEN** 提交的接入类型不属于 `HTTP` 或 `MCP`
- **THEN** 系统拒绝保存并指明非法字段

### Requirement: 入出参契约与前置校验

每个工具版本 SHALL 声明输入与输出的 JSON Schema。执行前的参数校验必须在发起外部请求之前完成。

#### Scenario: 参数合法

- **WHEN** 以符合 Schema 的参数调用工具
- **THEN** 系统发起外部请求并返回符合输出 Schema 的结果

#### Scenario: 参数非法被拦截

- **WHEN** 缺少必填参数或参数类型不符
- **THEN** 系统返回参数校验错误，且不发起任何外部请求

#### Scenario: 输出不符合契约

- **WHEN** 外部服务返回的结构不符合输出 Schema
- **THEN** 系统将本次调用标记为失败并保留原始响应的摘要供排查

### Requirement: 工具版本不可变

工具的定义、Schema、URL 模板或认证配置发生变更 SHALL 产生新版本。已生成的版本不得原地修改。

#### Scenario: 修改 Schema 生成新版本

- **WHEN** 开发者修改某工具参数的必填项
- **THEN** 系统创建新版本，引用旧版本的 Agent 版本仍指向旧契约

### Requirement: 风险等级

每个工具版本 SHALL 声明风险等级（只读、写操作、高风险），风险等级随版本保存并可查询。

#### Scenario: 标记高风险工具

- **WHEN** 开发者将某工具版本标记为高风险
- **THEN** 该工具版本在查询与调用记录中呈现高风险标记

### Requirement: 租户授权

工具 SHALL 支持授权给指定租户。未获授权的租户不得调用该工具，授权撤销后新调用必须被拒绝。

#### Scenario: 未授权租户调用

- **WHEN** 某租户的 Agent 执行中调用未授权给本租户的工具
- **THEN** 系统拒绝该次工具调用并记录为权限失败

#### Scenario: 授权撤销后调用

- **WHEN** 某工具对某租户的授权被撤销后该租户再次调用
- **THEN** 系统拒绝该次调用

### Requirement: 调用超时约束

系统 SHALL 对工具调用施加超时上限。超时的调用必须被终止并记录，不得无限等待外部服务。

#### Scenario: 外部服务超时

- **WHEN** 工具调用的外部服务在超时上限内未响应
- **THEN** 系统终止本次调用并将执行标记为失败，同时记录超时原因

### Requirement: MCP 工具契约

每个 `MCP` 工具版本 SHALL 声明传输方式、服务端地址、远端工具名与调用超时上限。传输方式仅允许远程 HTTP 类传输（`streamable_http`、`sse`），平台 SHALL NOT 在自身进程内拉起远端服务或子进程（即不提供 `stdio` 传输）。服务端地址必须是绝对 `http(s)` 地址；远端工具名必填且不为空。

#### Scenario: 缺少远端工具名

- **WHEN** 提交的 `MCP` 工具未声明远端工具名
- **THEN** 系统拒绝保存，并指明缺失字段

#### Scenario: 声明 stdio 传输

- **WHEN** 提交的 `MCP` 工具把传输方式声明为 `stdio`
- **THEN** 系统拒绝保存，因为平台不托管远端进程

#### Scenario: 非法的服务端地址

- **WHEN** 提交的服务端地址不是绝对 `http(s)` 地址
- **THEN** 系统拒绝保存，并指明地址字段非法

#### Scenario: 超时超出上限

- **WHEN** 提交的调用超时超过平台上限
- **THEN** 系统拒绝保存，并指明超时字段的取值范围

### Requirement: MCP 工具调用执行

`MCP` 工具的执行 SHALL 与 `HTTP` 工具共用同一套前置约束：发起远端调用前完成入参 Schema 校验、租户授权检查与高风险拦截；调用受超时上限约束；返回后按声明的输出 Schema 校验。远端超时、远端报错、网络失败与输出不符合契约 SHALL 映射为可识别的平台错误码，平台不得把远端原始错误响应直接透给调用方。首次实现 SHALL NOT 对失败的写操作自动重试。

#### Scenario: 成功调用 MCP 工具

- **WHEN** 以符合输入 Schema 的参数调用已授权的 `MCP` 工具版本，且远端正常返回
- **THEN** 系统返回符合输出 Schema 的结果，并记录本次调用

#### Scenario: 远端声明执行失败

- **WHEN** 远端返回执行失败标记
- **THEN** 系统把本次调用标记为失败，保留错误摘要，调用方收到工具错误码

#### Scenario: 远端超时

- **WHEN** 远端在超时上限内未返回
- **THEN** 系统终止本次调用，返回超时错误码，并记录超时原因

#### Scenario: 输出不符合契约

- **WHEN** 远端返回的内容不符合声明的输出 Schema
- **THEN** 系统把本次调用标记为失败并保留响应摘要供排查

#### Scenario: 未授权的租户调用

- **WHEN** 某租户的 Agent 执行中调用未授权给本租户的 `MCP` 工具
- **THEN** 系统在发起远端调用之前拒绝，并记录为权限失败

#### Scenario: 高风险工具未获放行

- **WHEN** 调用被标记为高风险且未显式放行
- **THEN** 系统在发起远端调用之前拒绝，并记录为高风险拦截

### Requirement: MCP 调用可追溯

每次 `MCP` 工具调用 SHALL 产生与 `HTTP` 工具同构的调用记录，包含所属租户、工具标识、工具版本、远端工具名、参数摘要、耗时、状态与错误码，并关联同一次执行的 `run_id` 与 `trace_id`。参数与返回值按敏感级别脱敏后入库。

#### Scenario: 按 执行 追溯 MCP 调用

- **WHEN** 一次执行中调用了 `MCP` 工具
- **THEN** 该次执行的轨迹中可以看到这次调用及其远端工具名、耗时与状态

#### Scenario: 敏感字段不入库

- **WHEN** `MCP` 工具的参数包含敏感字段
- **THEN** 调用记录中的参数为脱敏后的摘要，不含原值
