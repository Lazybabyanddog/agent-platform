# Spec Delta

## ADDED Requirements

### Requirement: MCP 工具探测

系统 SHALL 提供 `MCP` 工具探测能力：以传输方式、服务端地址与鉴权配置连接远端，取得远端当前声明的工具清单，每个条目包含远端工具名、用途描述与入参 Schema。该能力 SHALL 仅用于注册前的契约获取，SHALL NOT 创建或修改工具、SHALL NOT 产生工具版本、SHALL NOT 写入工具调用记录。探测 SHALL 受平台超时上限约束，并把远端认证失败、超时、不可达与协议错误归一为可区分的结论，不得把远端原始错误响应直接透给调用方。探测的传输方式 SHALL 仅允许远程 HTTP 类传输（`streamable_http`、`sse`），平台 SHALL NOT 在自身进程内拉起远端服务或子进程。

#### Scenario: 探测返回工具清单

- **WHEN** 以合法的服务端地址与传输方式发起探测，且远端正常响应
- **THEN** 系统返回远端可用工具清单，包含远端工具名、用途描述与入参 Schema

#### Scenario: 探测不改变注册表

- **WHEN** 一次探测成功返回工具清单
- **THEN** 工具注册表中不新增或修改任何工具，也不产生任何工具版本

#### Scenario: 探测认证失败

- **WHEN** 远端因凭据无效拒绝探测
- **THEN** 系统返回认证失败结论，且不透出远端原始错误响应

#### Scenario: 探测超时

- **WHEN** 远端在超时上限内未响应
- **THEN** 系统终止探测并返回超时结论

#### Scenario: 远端无可探测工具

- **WHEN** 远端连接成功但工具清单为空
- **THEN** 系统返回成功结论并携带空清单，而不是报告失败

#### Scenario: 声明 stdio 传输

- **WHEN** 探测请求把传输方式声明为 `stdio`
- **THEN** 系统拒绝该请求，因为平台不托管远端进程
