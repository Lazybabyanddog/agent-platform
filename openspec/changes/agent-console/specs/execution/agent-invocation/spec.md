# Spec Delta

## MODIFIED Requirements

### Requirement: 同步调用入口

系统 SHALL 提供同步调用接口，接收 Agent 标识、环境、输入与可选会话标识。受理时 MUST 校验 Agent 状态，停用或归档的 Agent SHALL 失败关闭。会话标识首次出现时，系统 SHALL 解析该环境的发布指针并固定发布记录与版本标识；会话已存在时，MUST 使用该会话绑定的发布记录与版本，不得重新解析发布指针。

#### Scenario: 成功调用已发布 Agent

- **WHEN** 调用方以合法输入调用 PROD 环境已发布的 Agent
- **THEN** 系统返回执行结果、运行标识与追踪标识

#### Scenario: 目标环境无发布

- **WHEN** 调用方调用的环境尚无发布指针
- **THEN** 系统返回未找到发布的结果，不执行任何 Agent 逻辑

#### Scenario: 调用未授权 Agent

- **WHEN** 调用方对该 Agent 无调用权限
- **THEN** 系统返回无权限结果，且不创建执行记录

#### Scenario: 调用已停用的 Agent

- **WHEN** 调用方调用一个被停用的 Agent
- **THEN** 系统拒绝执行并返回 Agent 已停用的原因，不创建执行记录

#### Scenario: 会话已存在时复用绑定

- **WHEN** 调用方携带一个已绑定了版本 3 的会话标识发起调用，而当前生效版本已是 4
- **THEN** 本次调用使用版本 3 执行

### Requirement: 按快照执行

执行 MUST 只使用该次执行所确定的版本快照内容。执行期间被引用资源产生新版本或被修改，均不得影响本次执行。同一会话的后续轮 MUST 使用会话绑定的版本快照，不得混用其他版本的配置。

#### Scenario: 执行期间发布新版本

- **WHEN** 某次执行进行中该 Agent 发布了新版本
- **THEN** 本次执行仍按原版本快照完成

#### Scenario: 执行期间上游资源变更

- **WHEN** 执行过程中被引用的 Prompt 生成新版本
- **THEN** 本次执行继续使用快照中记录的旧版本内容

#### Scenario: 会话跨多轮沿用同一快照

- **WHEN** 同一会话已执行三轮，期间该 Agent 发布了新版本
- **THEN** 第四轮仍使用会话绑定的版本快照

### Requirement: 执行记录

每次受理的调用 SHALL 创建一条运行记录，固定记录租户、Agent、调用者、会话标识（如提供）、运行种类与追踪标识，并记录开始与结束时间、状态。正式运行 MUST 记录发布记录与版本标识；预览运行 MUST 标注为预览并记录所用配置的摘要，且不关联发布记录。

#### Scenario: 调用成功后的记录

- **WHEN** 一次调用成功返回
- **THEN** 该运行记录状态为成功且可追溯其发布记录与版本身份

#### Scenario: 调用失败后的记录

- **WHEN** 一次调用因模型错误、工具错误或预算上限失败
- **THEN** 运行记录保留失败状态与可读的失败原因分类

#### Scenario: 会话调用的记录

- **WHEN** 同一会话发起的多次调用完成
- **THEN** 每条运行记录都带有该会话标识，可按会话聚合查询

#### Scenario: 预览调用的记录

- **WHEN** 一次预览执行完成
- **THEN** 运行记录被标注为预览且记录配置摘要，不包含发布记录

## ADDED Requirements

### Requirement: 预览执行

系统 SHALL 支持预览执行：以临时配置引用（模型、Prompt、工具与运行策略）组装配置并执行一次，装配与校验 MUST 与生成版本使用相同规则。预览执行 MUST NOT 生成 Agent 版本或移动任何发布指针。预览执行 MUST 与正式调用一样经过服务端工具二次授权、步骤上限、超时与 Token 预算约束。响应 SHALL 包含该配置的摘要值，供调用方判断配置是否已存在对应版本。

#### Scenario: 预览执行成功

- **WHEN** 调用方以一组可用引用发起预览执行
- **THEN** 系统返回回答、执行轨迹与配置摘要，且不产生版本

#### Scenario: 预览请求未授权工具

- **WHEN** 模型在预览中选择了一个当前租户未获授权的工具
- **THEN** 系统拒绝该工具调用并记录失败原因，与正式调用一致

#### Scenario: 预览触发预算上限

- **WHEN** 预览执行达到临时配置声明的最大步骤数
- **THEN** 系统终止执行并返回步骤上限导致的失败结果

#### Scenario: 预览引用不可用

- **WHEN** 预览请求中的 Prompt 版本已被停用
- **THEN** 系统在受理阶段拒绝并指出该资源，不创建运行记录
