## 3. 失败分类与回灌

- [x] 3.1 `ToolResult` 增加 `details` 与 `recoverable`；适配层保留异常详情并按白名单（`INPUT_INVALID`、`TOOL_TIMEOUT`、`TOOL_HTTP_ERROR`、`TOOL_MCP_ERROR`、`RESOURCE_UNAVAILABLE`）设置可恢复标记；单测逐个错误码断言。
- [x] 3.2 参数校验失败的详情包含参数路径与具体原因，并进入回灌正文；单测断言正文同时出现 `arguments.<参数名>` 与原因。
- [x] 3.3 节点层失败分流：可恢复失败追加工具消息继续循环，不可恢复失败终止并返回原因；单测覆盖两条分支及对应消息序列。
- [x] 3.4 回灌正文统一信封（`status`/`recoverable`/`code`/`message`/`fields`/`hint`），业务终态使用 `no_data`；单测断言两种正文结构稳定可解析。
- [x] 3.5 相同工具与相同参数的重复调用短路：第二次直接回灌终态说明且不发起工具调用；单测断言 `ToolPort` 仅被调用一次。
- [x] 3.6 业务终态声明生效：空结果被声明为终态时返回 `no_data`、不可恢复、调用记录为成功；单测断言模型收到终态文案。
- [x] 3.7 中间失败留痕：工具先失败后被模型纠正并最终成功时，执行事件与工具调用记录仍可查到那次失败分类；集成测试断言。
- [x] 3.8 文档：补充「可恢复/不可恢复/业务终态」三类失败的判定表与新增错误码说明（`docs/tool-contract.md`）。

- [x] 4.1 Agent 版本支持 `runtime_context` 声明，白名单为 `now`、`timezone`，未知项拒绝保存并指明非法项；单测覆盖合法、非法、缺省三种声明。
- [x] 4.2 声明写入快照并参与配置摘要与版本对比；单测断言仅声明不同则摘要不同，且对比结果包含该差异。
- [x] 4.3 实现上下文消息生成：取服务端当前时间与时区，输出含日期、时间、星期与时区标识的单行文本；单测注入固定时钟断言逐字输出。
- [x] 4.4 渲染阶段按声明在系统消息之后、历史之前插入上下文消息；未声明版本不插入；单测覆盖两种消息序列。
- [x] 4.5 上下文消息不进入会话历史：同一会话连续两轮后，检查点历史不含上下文消息；集成测试断言。
- [x] 4.6 同一 run 内上下文取值固定：run 开始时取一次，同轮多次模型调用复用同一值；单测以跨时间边界的固定时钟断言。
- [x] 4.7 调用方输入无法覆盖上下文：输入中出现同名键时忽略该值；单测断言伪造值不生效。
- [x] 4.8 文档：说明声明机制、支持的上下文项、与 Prompt 模板占位符的关系（无需在模板中声明）（`docs/runtime-context.md`）。
