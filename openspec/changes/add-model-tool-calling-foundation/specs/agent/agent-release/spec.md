# Spec Delta

## ADDED Requirements

### Requirement: 运行时上下文依赖声明

Agent 版本 SHALL 声明本次执行所需的运行时上下文项，至少支持当前日期时间与时区。声明随版本固化进快照，执行时由平台按声明提供。

- 上下文值 MUST 由平台在服务端产生，MUST NOT 由调用方通过输入提供或覆盖。
- 未在版本中声明的上下文项 MUST NOT 出现在本次执行发送给模型的任何消息中。
- 声明项 MUST 来自平台支持的集合；包含未知项的版本 MUST 被拒绝保存并指明非法项。
- 声明内容 MUST 参与配置摘要与版本对比。

#### Scenario: 声明时间上下文

- **WHEN** 某 Agent 版本声明需要当前日期时间与时区
- **THEN** 该版本的每次执行在发送给模型的消息中包含由服务端产生的当前日期时间与时区

#### Scenario: 未声明的上下文不注入

- **WHEN** 某 Agent 版本未声明需要当前日期时间
- **THEN** 本次执行发送给模型的消息中不包含平台提供的当前日期时间

#### Scenario: 调用方无法伪造上下文

- **WHEN** 调用方在输入中提供了与声明项同名的值
- **THEN** 系统使用服务端产生的值，调用方提供的值不覆盖它

#### Scenario: 未知声明项被拒绝

- **WHEN** 生成版本时声明了平台不支持上下文项
- **THEN** 系统拒绝生成版本并指明非法项

## MODIFIED Requirements

### Requirement: 版本生成即固化快照

生成 Agent 版本时，系统 SHALL 把模型、Prompt、工具的具体版本引用、参数覆盖与运行时上下文依赖声明固化进不可变快照，并计算配置摘要。快照生成后不随被引用资源的变化而变化。

#### Scenario: 生成版本快照

- **WHEN** 开发者为绑定了一个模型、一个 Prompt 与一个工具的 Agent 生成版本
- **THEN** 系统保存包含三者确切版本信息的快照与配置摘要

#### Scenario: 声明进入快照

- **WHEN** 开发者为版本声明了需要的运行时上下文项
- **THEN** 该声明保存在版本快照中，且相同资源与相同声明生成相同配置摘要

#### Scenario: 被引用资源变更不影响旧版本

- **WHEN** 关联的 Prompt 在之后生成新版本
- **THEN** 已生成的 Agent 版本快照内容与其配置摘要保持不变

#### Scenario: 同配置重复生成得到相同摘要

- **WHEN** 以完全相同的资源配置连续生成两个版本
- **THEN** 两个版本的配置摘要一致，版本号不同

### Requirement: 版本对比

系统 SHALL 支持对比同一 Agent 的两个版本，展示模型、Prompt、工具版本绑定、运行时上下文依赖声明与运行策略的差异。

#### Scenario: 对比两个版本

- **WHEN** 开发者选择版本 1 与版本 4 对比
- **THEN** 系统返回资源绑定、上下文依赖声明与策略参数的差异结果
