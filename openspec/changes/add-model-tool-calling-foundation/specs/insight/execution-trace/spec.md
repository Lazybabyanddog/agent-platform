# Spec Delta

## MODIFIED Requirements

### Requirement: 模型调用记录

系统 SHALL 记录每次模型调用的模型标识、输入与输出 Token 数、耗时、状态与错误分类，并关联运行标识。记录 MUST 同时保留本次调用实际携带的工具卡摘要，包括工具数量与每个工具的名称、描述与参数契约摘要，使「模型实际看到了什么」可在事后复核。

- 工具卡摘要 MUST 随每次模型调用分别记录，不得只记录本次执行首次调用时的工具卡。
- 工具卡摘要中的描述与参数说明 MUST 按工具版本契约原文保留，不得以占位符替代。
- 未携带任何工具的调用 MUST 明确记为工具数量为零，与「未记录」可区分。

#### Scenario: 成功调用被记录

- **WHEN** 一次模型调用成功返回
- **THEN** 系统落一条记录，包含模型标识、Token 数与耗时

#### Scenario: 失败调用被记录

- **WHEN** 模型调用因限流、超时或供应商错误失败
- **THEN** 系统落一条失败记录并包含可区分的错误分类

#### Scenario: 工具卡随调用落库

- **WHEN** 一次模型调用携带了两个工具
- **THEN** 该次调用的记录包含工具数量为二，以及两个工具的名称、描述与参数契约摘要

#### Scenario: 无工具的调用可区分

- **WHEN** 一次模型调用未携带任何工具
- **THEN** 记录中工具数量为零，而不是缺少该字段
