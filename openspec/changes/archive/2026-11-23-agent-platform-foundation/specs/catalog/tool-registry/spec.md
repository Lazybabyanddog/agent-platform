# Spec Delta

## Purpose

把 Agent 可调用的内部 API 与业务服务注册为带契约、带版本、带风险等级的受管工具，使工具调用在参数、权限与超时上可被服务端强制约束。

## ADDED Requirements

### Requirement: 工具注册

系统 SHALL 支持注册 HTTP 类型工具，配置项包含名称、面向模型的用途描述、请求方法、URL 模板、认证凭据引用与状态。

#### Scenario: 注册 HTTP 工具

- **WHEN** 开发者提交工具名称、用途描述、方法与 URL 模板
- **THEN** 系统创建工具并返回其标识与首个版本

#### Scenario: 缺少用途描述被拒绝

- **WHEN** 提交的工具未提供描述
- **THEN** 系统拒绝保存，因为缺少描述会导致模型无法正确选择工具

### Requirement: 入出参契约与前置校验

每个工具版本 SHALL 声明输入与输出的 JSON Schema。执行前的参数校验必须在发起外部请求之前完成。

#### Scenario: 参数合法

- **WHEN** 以符合 Schema 的参数调用工具
- **THEN** 系统发起外部请求并返回符合输出 Schema 的结果

#### Scenario: 参数非法被拦截

- **WHEN** 缺少必填参数或参数类型不符
- **THEN** 系统返回参数校验错误，且不发起任何外部请求

#### Scenario: 输出不符合契约

- **WHEN** 外部服务返回的结构不符合输出 Schema
- **THEN** 系统将本次调用标记为失败并保留原始响应的摘要供排查

### Requirement: 工具版本不可变

工具的定义、Schema、URL 模板或认证配置发生变更 SHALL 产生新版本。已生成的版本不得原地修改。

#### Scenario: 修改 Schema 生成新版本

- **WHEN** 开发者修改某工具参数的必填项
- **THEN** 系统创建新版本，引用旧版本的 Agent 版本仍指向旧契约

### Requirement: 风险等级

每个工具版本 SHALL 声明风险等级（只读、写操作、高风险），风险等级随版本保存并可查询。

#### Scenario: 标记高风险工具

- **WHEN** 开发者将某工具版本标记为高风险
- **THEN** 该工具版本在查询与调用记录中呈现高风险标记

### Requirement: 租户授权

工具 SHALL 支持授权给指定租户。未获授权的租户不得调用该工具，授权撤销后新调用必须被拒绝。

#### Scenario: 未授权租户调用

- **WHEN** 某租户的 Agent 执行中调用未授权给本租户的工具
- **THEN** 系统拒绝该次工具调用并记录为权限失败

#### Scenario: 授权撤销后调用

- **WHEN** 某工具对某租户的授权被撤销后该租户再次调用
- **THEN** 系统拒绝该次调用

### Requirement: 调用超时约束

系统 SHALL 对工具调用施加超时上限。超时的调用必须被终止并记录，不得无限等待外部服务。

#### Scenario: 外部服务超时

- **WHEN** 工具调用的外部服务在超时上限内未响应
- **THEN** 系统终止本次调用并将执行标记为失败，同时记录超时原因
