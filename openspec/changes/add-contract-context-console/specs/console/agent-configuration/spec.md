# Spec Delta

## Purpose

让 Agent 配置页成为版本内容的完整编辑面：除模型、Prompt、工具与运行策略外，作者还能声明这次执行需要平台注入哪些运行时事实，并在版本对比中看到声明的变化，而不是只能靠接口维护。

## ADDED Requirements

### Requirement: 运行时上下文声明

配置页 SHALL 提供运行时上下文声明，至少包含「当前时间」与「时区」两项，默认都不声明；界面 SHALL 说明声明后平台在每次执行时注入一条独立消息、不写入会话历史，且不要求 Prompt 模板写占位符。声明 SHALL 随保存写入版本；以某版本为基准编辑时 SHALL 回显该版本的声明；作者未改动声明时保存 MUST NOT 丢弃既有声明。作者清空全部声明时 SHALL 明确提示这会让模型看不到平台时间与时区。

#### Scenario: 声明时间与时区

- **WHEN** 作者勾选「当前时间」与「时区」并保存版本
- **THEN** 新版本记录这两项声明，执行时模型侧可见对应事实

#### Scenario: 基于已有版本编辑但未改声明

- **WHEN** 某版本已声明「当前时间」，作者只更换模型后保存新版本
- **THEN** 新版本仍保留该声明，不被清空

#### Scenario: 清空声明

- **WHEN** 作者取消全部声明并保存
- **THEN** 界面在提交前提示模型将失去平台时间与时区，确认后新版本不含声明

### Requirement: 预览沿用编辑态的声明

配置页预览 SHALL 携带当前编辑态的运行时上下文声明，使预览执行与保存后的正式执行一致；预览 MUST NOT 因此写入版本或改变发布指针。声明尚未保存时 SHALL 仍可通过预览验证其效果。

#### Scenario: 未保存声明先预览

- **WHEN** 作者勾选「当前时间」后直接发起预览、尚未保存版本
- **THEN** 预览回答基于注入了当前时间的上下文，版本列表没有新增版本

### Requirement: 版本对比包含运行时上下文

版本对比 SHALL 展示两个版本在运行时上下文声明上的差异，列出各自声明的项；两者一致时 SHALL 明确标注未变更，而不是遗漏该维度。

#### Scenario: 声明从无到有

- **WHEN** 作者对比未声明与声明「当前时间」的两个版本
- **THEN** 对比区域显示该维度已变更，并列出前后各自的声明项

#### Scenario: 声明未变化

- **WHEN** 两个版本的声明相同
- **THEN** 对比区域标注该维度未变更
