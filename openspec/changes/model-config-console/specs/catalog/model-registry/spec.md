# Spec Delta

## MODIFIED Requirements

### Requirement: 供应商接入

系统 SHALL 支持注册 OpenAI 兼容接口的模型供应商，配置项包含名称、Base URL、凭据引用、区域与可用状态。供应商可属于平台级或指定租户。区域为可选信息，仅用于展示与筛选，不参与请求路由。系统 SHALL 支持在创建后变更供应商的名称、Base URL、区域、凭据引用与可用状态；变更 Base URL 或凭据引用 MUST 在接口响应与界面中声明其影响范围。

#### Scenario: 注册供应商

- **WHEN** 管理员提交名称、Base URL 与凭据引用，可选提交区域
- **THEN** 系统创建供应商记录并返回其标识、区域与状态

#### Scenario: 变更可展示配置

- **WHEN** 管理员修改供应商名称或区域
- **THEN** 系统保存变更，后续查询与列表展示新值，已发布 Agent 版本的调用行为不受影响

#### Scenario: 变更 Base URL 或凭据引用

- **WHEN** 管理员修改供应商的 Base URL 或凭据引用
- **THEN** 系统保存变更，并在响应与界面中提示该变更对引用此供应商的全部已发布 Agent 版本立即生效

#### Scenario: 停用供应商

- **WHEN** 供应商被停用
- **THEN** 系统拒绝在其下注册新模型，并使其下模型不再可用于新的 Agent 版本绑定与发布体检；已发布 Agent 版本的调用 MUST 继续按其快照执行，不因供应商停用而被拒绝

#### Scenario: 在停用供应商下注册模型

- **WHEN** 管理员尝试在已停用的供应商下注册模型
- **THEN** 系统拒绝创建并返回供应商不可用原因

### Requirement: 模型注册与标识分离

系统 SHALL 为每个模型分别保存平台内逻辑编码与供应商实际模型标识。模型必须声明上下文窗口、输入输出模态与能力标签。逻辑编码在租户内唯一，MUST NOT 变更；模型所属供应商 MUST NOT 变更，需要更换供应商时 MUST 新建模型替代。供应商实际模型标识、上下文窗口、模态、能力标签与参数模板 SHALL 可变更，其变更只影响之后生成的 Agent 版本。

#### Scenario: 注册模型

- **WHEN** 管理员在供应商下提交逻辑编码、实际模型标识与上下文窗口
- **THEN** 系统创建模型记录，二者分别存储且可独立查询

#### Scenario: 逻辑编码冲突

- **WHEN** 同一租户下提交已存在的模型逻辑编码
- **THEN** 系统拒绝创建并返回冲突错误

#### Scenario: 变更实际模型标识

- **WHEN** 管理员修改某模型的供应商实际模型标识
- **THEN** 系统保存新值，此后生成的 Agent 版本使用新标识，已生成的版本按其快照中的原标识继续运行

#### Scenario: 尝试变更不可变字段

- **WHEN** 管理员提交对逻辑编码或所属供应商的变更
- **THEN** 系统拒绝该变更并返回不可变字段的具体原因

### Requirement: 参数模板与取值约束

系统 SHALL 为模型维护可配置的调用参数（温度、采样、最大输出长度、超时等）及其合法范围。超出范围的参数在保存或执行前必须被拒绝。参数模板 MUST 只接受平台受支持的参数键，不受支持的键 MUST 在保存时被拒绝，不得静默丢弃。超时参数以秒为单位，取值 MUST 大于零且不超过平台同步调用上限。

#### Scenario: 参数越界被拒绝

- **WHEN** 提交的温度值超出该模型声明的合法范围
- **THEN** 系统拒绝保存并返回可定位到该参数的校验错误

#### Scenario: 使用模型参数模板

- **WHEN** 执行时未显式覆盖参数
- **THEN** 执行使用该模型参数模板中的值

#### Scenario: 超时参数生效

- **WHEN** 模型参数模板声明了超时且该模型被某 Agent 版本引用
- **THEN** 单次模型调用使用模板超时值与本次运行可用预算中的较小者，运行级预算始终优先

#### Scenario: 超时参数超出平台上限

- **WHEN** 提交的超时值超过平台同步调用上限
- **THEN** 系统拒绝保存并返回该字段的具体上界

#### Scenario: 提交不受支持的参数键

- **WHEN** 参数模板包含平台未支持的参数键
- **THEN** 系统拒绝保存并指明不被支持的键名

### Requirement: 连通性测试

系统 SHALL 提供供应商级与模型级连通性测试能力。测试结果 MUST 区分成功与失败原因，至少可区分：凭据有效且模型存在、凭据有效但模型不在上游返回清单、凭据有效但上游未提供模型清单、凭据无效、请求超时、无法连通。测试结果 SHALL 记录测试时间、耗时、HTTP 状态码与上游返回的模型清单及命中项，并保留历史以便追溯。任何测试响应都 MUST NOT 出现凭据原文。

#### Scenario: 测试成功

- **WHEN** 管理员对某模型发起连通性测试且上游正常响应且返回清单中包含该模型的供应商实际标识
- **THEN** 系统返回成功结果、耗时与命中的上游模型标识

#### Scenario: 模型不在上游清单

- **WHEN** 上游正常响应且凭据有效，但返回清单中不含该模型声明的实际标识
- **THEN** 系统返回"模型不存在"结论，并附上游返回的清单以便管理员核对

#### Scenario: 上游不提供模型清单

- **WHEN** 上游正常响应且凭据有效，但未返回可解析的模型清单
- **THEN** 系统返回"凭据有效、模型未验证"结论，不与成功或失败混淆

#### Scenario: 测试失败

- **WHEN** 供应商返回认证失败或超时
- **THEN** 系统返回失败结果与错误分类，且不返回凭据原文

#### Scenario: 查询测试历史

- **WHEN** 管理员查看某供应商或模型的连通性测试历史
- **THEN** 系统按时间倒序返回历次结论、耗时、状态码与命中的上游模型标识

### Requirement: 不可用模型失败关闭

当模型或其供应商处于停用、凭据不可用状态时，引用该模型的 Agent 版本装配与发布 MUST 失败关闭并给出明确原因，不得静默降级到其他模型。已发布 Agent 版本的调用 MUST NOT 因为模型或供应商之后被停用而失败；凭据不可解析时仍 MUST 失败关闭。

#### Scenario: 发布引用停用模型

- **WHEN** 某 Agent 版本引用已停用的模型
- **THEN** 发布被拒绝并返回具体不可用原因

#### Scenario: 装配引用停用供应商下的模型

- **WHEN** 开发者尝试用所属供应商已停用的模型生成 Agent 版本
- **THEN** 系统拒绝该引用并指明供应商不可用

#### Scenario: 执行时模型被停用

- **WHEN** Agent 已发布，其引用的模型或供应商在之后被停用并被调用
- **THEN** 本次执行按其快照正常发起调用，不因停用被拒绝，也不切换到其他模型

#### Scenario: 凭据不可解析

- **WHEN** 调用所需凭据已被禁用或删除
- **THEN** 本次执行返回失败状态与原因，且不产生伪造的成功结果
