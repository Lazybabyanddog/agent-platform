# Spec Delta

## MODIFIED Requirements

### Requirement: 引用不可用时失败关闭

当 Agent 版本引用的资源不可用时，失败时机 MUST 按资源类型区分。工具被停用、被删除或不再对本租户授权时，发布与该版本发布后的调用 MUST 失败关闭并给出具体原因。模型或其供应商被停用时，只 MUST 阻断新的版本装配与发布体检，已发布版本的调用 MUST 继续按其快照执行，不得因停用而拒绝，也不得静默切换到其他模型。任何情况下都不得以伪造的成功结果掩盖不可用。

#### Scenario: 引用资源被撤销授权

- **WHEN** 某 Agent 版本引用的工具对当前租户的授权被撤销后发起调用
- **THEN** 调用失败并返回被撤销授权的具体资源

#### Scenario: 发布引用已停用资源

- **WHEN** 尝试发布引用了已停用 Prompt 版本的 Agent 版本
- **THEN** 发布被拒绝并返回具体不可用原因

#### Scenario: 生成版本引用已停用模型

- **WHEN** 开发者为引用了已停用模型或其供应商已停用的模型生成 Agent 版本
- **THEN** 系统拒绝该版本装配并指明不可用的模型或供应商

#### Scenario: 已发布版本在模型停用后继续调用

- **WHEN** Agent 已发布，其引用的模型或供应商在发布之后被停用
- **THEN** 调用按其快照绑定的模型继续执行，不被停用状态拒绝
